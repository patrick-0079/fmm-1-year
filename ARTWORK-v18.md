# 两条花园小路、月芽阵与窗边贝斯

使用内置 imagegen 制作三张母图。运行 `npm run art:lanes` 可重新生成游戏使用的 WebP；常规构建无需重新生成美术。

| 原稿 → 游戏贴图 | 用途 |
| --- | --- |
| `src/assets/garden-lanes-v18.png` → `garden-lanes-v18.webp` | 只取南侧分岔石径与东北桥头两片重绘区域，用柔边蒙版合回原庭院。其他家具、放映屏、中央花门仍与原画对齐。 |
| `src/assets/country-wicket-v18.png` → `country-wicket-v18.webp` | 庭院南门使用低矮的双扇；小镇南街以原画的铸铁路灯作西侧门柱，只在东侧接一扇矮门，保留街边的灯与栅栏。北桥与北街台阶共用蓝丝带木路牌。 |
| `src/assets/white-bass-v18.png` → `white-bass-v18.webp` | 四弦电贝斯与琴架共用一个脚底锚点。琴架占用 14 × 7 个逻辑像素；琴身和琴颈可点击，不会把床边通道封住。 |

两条路的入、出坐标与实体通行判定在 `src/gate-layout.ts`，传送时人物朝向相应地图内部。七朵花沿用原图集，各自高 14–16 个逻辑像素，点击与靠近的范围没有随图片缩小。花海的月芽阵由 `src/moon-circle.ts` 直接绘在草地层：十颗月石、一圈断续的光纹和一枚双叶刻纹。走入阵心才自动返回，抵达花海时站在阵外。系统开启减少动态效果时，阵纹和小花闪光保持静止。

本地开发页 `/tests/exploration-fixture.html` 的「验收两条通路、传送阵与贝斯」使用独立存档，实际走过门槛和木桥、点击花瓣、拨弦、踏入月芽阵，并展示游戏画布实拍。
