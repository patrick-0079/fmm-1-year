# 周年徽章与交互验收

本记录含彩蛋答案。首次验收于 2026 年 11 月 22 日，测试分支为 `preview`。11 月 26 日用 390px 触屏窗口复验，同一新档收齐 12 封来信和 55 枚徽章，刷新后 55 枚徽章全部保留。11 月 27 日在 1366px 桌面窗口重新走完路线，同一新档收齐 12 封来信与 57 枚徽章，包含浅笑首胜，刷新后仍为 57 枚。

## 怎么复验

在仓库根目录运行 `npm run check`。安装了 Playwright 与浏览器的开发机还可以执行 `node scripts/verify-badge-route.mjs 1366`，把宽度换成 `390` 或 `320` 可检查窄屏。外部安装的 Playwright 可通过 `PLAYWRIGHT_MODULE` 指定。Windows 默认使用 Edge。

完整路线从新档的 0 枚开始，先取得全部互动徽章，再取得 3 枚计时徽章，最后刷新核对收藏。同一次路线保留所有收信、收集和游戏记录。为让结果可重复，长距离步行在测试中直接定位到靠近点，小游戏读取当前棋盘、固定部分随机开局，按游戏的输入和计分规则游玩。前台计时使用浏览器虚拟时钟，每次推进 10 秒。寻路碰撞、实际点击和遮挡另做检查。移动端使用触屏模拟。

## 可单独复跑的交互检查

- 在 `tests/exploration-fixture.html` 可单独运行小屋送别、复活便签、花园对白、收信、星盘、小游戏画幅和地图加载竞态。测试存档与正式存档隔离。
- `tests/interaction-target.test.ts` 遍历六张地图，逐个核对 103 个互动对象的停靠点、贴图中心和提示锚点。额外点选大屏两侧、信箱和相册分界、夜间萤火和七色花。寻路测试从地图出生点及休息点实际计算每段路线和碰撞。
- `tests/interaction-fixture.html` 和 `tests/interaction-prompt-fixture.html` 可复验连续开关面板、按住按键、移动后松开、取消触摸、键盘焦点和烟花跨场次计数。
- `tests/launch-build.integration.ts` 检查精简构建的文件隔离；影片、贴图缓存与坏档恢复另有单元测试。测试故障时使用隔离的浏览器存储和模拟错误响应。

## 浏览器故障复测

| 操作 | 观察结果 |
| --- | --- |
| 从小屋书桌前传送，连点目的地，再重复点击已经到达的地图 | 芙芙按可行走路线到门垫与狐狸会合。重复点击本图时保持原位置。目标地图加载失败后可以重试，小狐狸的漏摸次数只在成功出门后结算。 |
| 桌面点相册、信箱、大屏两侧；在 320px、390px 上直接轻触同一批物件 | 左侧背包入口避开了小屋桌面及花海传送阵。三种宽度各点选 18 处，同时检查夜间实际显示的 96 个互动中心与界面按钮的遮挡关系。 |
| 从小屋开一张照片，再让角色走到花园大屏；CDN 保持离线 | 鼠标和触屏都能在打开花园放映时取得「这一年有画面」。影片恢复后可继续播放。 |
| 地图返回标成 WebP 的损坏内容；影片也返回不可解码的完整文件 | 修复源文件后地图可以重试。视频重试重新下载，正常播放；已验证的有效贴图仍可离线使用。 |
| 第一个标签拆开 Rabe 的信，第二个标签切静音并保存，再从第一个标签重新探索 | 两边同步未读数量。清档后另一标签再次保存及刷新，徽章回到 0/44，两封开局信恢复未读。 |
| 阻止本地存储、损坏部分存档或中途切换地图 | 阻止存储后仍可游玩。独立存档分区的有效记录能保留；地图加载失败可返回小屋再试。 |
