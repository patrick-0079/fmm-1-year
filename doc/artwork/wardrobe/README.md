# 芙芙的衣橱

运行 `npm run art:wardrobe` 重建角色、鞋子、衣橱物品与桃桃的步态图集。浏览器开发页 `/tests/equipment-fixture.html` 使用游戏的实际绘制函数。

## 原画

ImageGen 以项目原有的粉发角色、两张休息立绘和宠物步态为参考。各套动作使用同一个姿势模板，透明底、暖梅色轮廓、平涂和一层阴影。每套衣服保留一种领型、一个主要装饰和清楚的下摆。

| 文件前缀 | 造型 |
| --- | --- |
| base | 原版淡紫睡衣，保留粉发卷和异色瞳 |
| rose | 蔷薇束腰、花瓣裙摆和一枚腰花 |
| mint | 奶油内衬、金色扣子和前襟敞开的薄荷短斗篷 |
| cloud | 雾蓝翻领睡衣、云朵口袋和长裤 |
| apricot | 杏桃色长睡裙、奶油圆领和一枚小领结 |
| sailor | 象牙白水手衫、藏蓝领、珊瑚红领巾和短裤 |
| honey | 鼠尾草绿短袖、麦芽黄背带裤和大前袋 |
| witch | 墨蓝钟形裙、梅紫尖角披肩和月牙扣，尖帽另放在头饰栏 |
| miko | 白色交领宽袖上衣、绯色褶袴、前腰结与白足袋 |

`*-walk.webp` 从上至下为正面、向左、向右和背面。每行三帧依次为待机和左右脚迈步。`*-rest.webp` 分别绘制长椅垂腿、花海屈膝坐地和枕上侧卧。基础角色的长椅姿势在 `bench.webp`。所有角色原画均使用素发，爱心和两根淡紫发卡从原版休息立绘中裁出，保留原来的心形、位置关系和像素边缘。

`witch-icons.webp` 收有女巫裙与尖帽的正面、侧面和后视图。`icons.webp` 与 `starter-icons.webp` 采用同一组平涂图标。每件保留一种辨识特征，例如兔耳包盖、新月胸针、莓果包轮廓或水手领巾。`flats.webp` 与 `boots.webp` 各有前视、侧视和后跟。桃桃使用四步、三方向的独立步态，侧身向右时镜像。

内置 ImageGen 参照芙芙的头型和原物品配色绘制了两张佩戴原画。

- `worn-hat.webp` 按正、左、右、背四向画同一顶软呢尖帽。靛紫帽尖后折，宽帽檐随着头型起伏，金月牙别在左鬓一侧。
- `worn-bags.webp` 上排是月兔背包、草莓背包和花环兔斜挎包的外侧，下排分别画出包的厚度和翻盖侧缘。肩带按穿戴方向连接包身，斜挎包落在左胯。长发和挥动的手臂会遮住一部分包体。

巫女服取自服装参考图左侧的白衣与绯袴。内置 ImageGen 的三张原画分别使用以下绘制要求。

- `miko-walk.webp` 沿用基础角色的粉色卷发、左绿右粉双眼与四向步态。白衣左襟压右襟，腰结留两根短带，绯袴用几道大褶表现。每一步都露出足袋和草履。
- `miko-rest.webp` 沿用休息图的四格构图。长椅上双脚自然下垂，花海坐姿把衣褶拢在屈起的膝旁，床上侧卧时枕头在左、脚在右。
- `miko-icon.webp` 采用初始衣橱图标的梅色轮廓和平涂，在透明底上画出整套衣服的正面，突出交领、宽袖、腰结和袴褶。

## 游戏图集

`fufu-garments.webp` 每行一套衣服，共 12 个站立与行走帧、两个坐姿和一个双宽睡姿。站立和落座以脚底为锚点，卧姿以床枕中心为锚点。`fufu-footwear.webp` 对应每套服装、每双鞋和每个非卧姿帧。背包里的物品、花园花环、礼盒奖品和星盘胸针共用 `wardrobe-icons.webp`。
