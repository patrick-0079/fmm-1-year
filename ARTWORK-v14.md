# 周年游园会美术与配乐

七幅小游戏背景、游园券封面及角色道具由内置 imagegen 生成。芙芙形象参考为项目内的 `ref/1.png`。场景和道具都是游戏本地资源。

| 源图 | 运行素材 |
| --- | --- |
| `src/assets/arcade-landscapes-v14.png` | 野餐布、月光小镇、云上甜点台和星屑矿井 |
| `src/assets/arcade-workshops-v14.png` | 缎带工坊、心愿信笺、晨露温室和游园券纪念照 |
| `src/assets/arcade-props-v14.png` | 飞行的芙芙、月兔、两种蛋糕台、星糖、糖蛇、芙芙绞盘和金色星矿 |

运行 `npm run art:festival` 会从上述图集裁切出 `src/assets/arcade-*-v14.webp`。棋盘图按 240×160 逻辑像素着色，游玩时按需加载当前场景。道具保留透明通道。该命令也会从人物原画的脚部轮廓重建 `src/assets/fufu-footwear-v14.webp`。

原创配乐《把晚安留给你》的谱面和乐器参数在 `src/lullaby.ts`。在开发页 `/tests/festival-preview.html` 可以试听和导出小屋、小镇两种编配的 WAV。
