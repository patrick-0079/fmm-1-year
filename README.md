# 芙眠眠一周年 · 晚安小世界

暖木色、薰衣草紫、樱花粉、薄荷绿与溪水蓝搭配的像素风 H5 周年探索游戏。控制 Q 版芙芙，探索晚安小屋、周年花园、勇气花园、周年小镇、镇上的七间室内和回声遗迹。集齐七色花后可进入彩蛋地图「花海」。全部逻辑在浏览器内运行，不需要后端、数据库或服务端函数。

## 沿途的居民

小镇的 18 位居民各有自己的对白。晚安信箱一开始就能读到 Kerry 和小艾门的信，其他信可以在散步时慢慢收齐。去邮局找红笺，她会把自己的信寄回小屋。花店的青芽会送一束能在背包「纪念物」里翻看的洋桔梗，栗栗会举起白板，把第一块草莓蛋糕留给你。银铃需要叫两次才会抬头。走远可以自然结束交谈，回头再聊也能试试其他回答。

四张地图的 29 位角色会随时段和见面次数聊起不同的事。寄信人送过信，再相遇时也会聊日常。想回看另一种回答，可以在以后遇到同一话题时再选一次。完整台词、玩家选项和触发条件收在[居民对白全录](doc/conversation.md)。

南街田边的小佑会递橘子，初遇后在清晨带来一封信。故里在烘焙屋旁请你猜她为什么会当跑腿员。游乐街上的浅笑会亮出她画的卡，清晨、白昼和星夜再去找她，可以参加召唤牌局，首胜获得「浅笑 · 赢下这一局」。

勇气花园南门内、石路左边住着园丁爷爷。回声遗迹南阶上方的守护者会在你答应试试谜题后赠送《遗迹手记》。已经点亮星纹砖的玩家也可以找她领书，听她送上祝福。

散步时可以停一停。小屋窗外有云经过，小狐狸偶尔把脸埋进尾巴。周年花园里，星星会收一收气球线，花瓣沿溪穿过木桥。勇气花园的园丁在拢土，水里有一枚随弯道转身的落叶。到小镇书屋前，可以看墨桃翻页、池鱼钻过荷叶，也可以沿街去看风吹彩旗。遗迹的听月泉偶尔落下一滴水。

清晨和深夜路过同一条街，有机会遇见不同的居民。看到谁正在散步，可以直接点他，他会停下来等芙芙。站在街角看一会儿，还能见到树梢翻叶、屋顶冒烟。开启「减少动态效果」时，居民会在自己的活动区内停下做事。

花海的水壶冒着热气。六只蓝水母分散在草间，北坡、东边的远草地和南缘都有机会遇见。放慢脚步站一会儿，最近的一只可能游到芙芙身侧。系统开启「减少动态效果」后，水母会留在草地原位，以转向回应芙芙。

## 开发和构建

需要 Node.js 22.12+（建议 Node.js 24）。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

日常修改后可运行 `npm run check`，依次执行全部单元/地图回归测试、TypeScript 检查和生产构建。默认开发地址为 `http://127.0.0.1:5173/`，生产预览为 `http://127.0.0.1:4173/`；端口被占用时以终端输出为准。正式站：[芙芙的晚安小世界](https://1-year.芙眠眠nemu.space/)。

开发服务器下可访问 `/tests/media-fixture.html` 检查图片、音视频和素材缺失提示。测试音视频在浏览器内临时生成，测试内容不会进入正式内容配置或生产构建。

`/tests/interaction-cues-fixture.html` 复用正式主页检查地图提示、E 键目标、切图和暂停恢复；使用独立标签页存档，不影响正常游玩记录。物件旁提示的窄屏布局、鼠标慢移与触屏点击也从此页验收。

`/tests/mobile-fixture.html` 提供 375 与 320 像素宽度的真实页面框架，用于检查手机布局、方向键、陷阱和地图内复活提示；同样不包含在生产构建中。

`/tests/interaction-fixture.html` 对真实控制器执行背包暂停、焦点、组合键、拆礼物中断与领奖及后台恢复检查，不写入存档。其他验收页、发布前检查和配置文件位置见 [维护手册](MAINTENANCE.md)。

生产产物在 `dist/`，可以部署到任意静态托管服务。它是一个单页网站及其本地资源文件，需通过 HTTP/HTTPS 访问，不能直接双击 HTML 使用 `file://` 打开。

## 本机存档与资源缓存

点击网页桌宠可调节大小、透明度或选择「隐藏小小芙」。隐藏后，点击游戏页底「重新探索」左侧的「小小芙」即可恢复，邀请函底部也有同名按钮。刷新会保留桌宠的显示状态和设置，重新打开不会重置游戏进度。

桌宠的 100% 为原先的 200%，可调范围为 50%～500%。拖动以人物轮廓为准，不再受素材透明留白限制；放大后也可以把人物拖到屏幕边缘。

游戏会自动保存，状态栏显示最近保存的地图和时间。移动时约每两秒记录一次位置，切换地图、坐下、躺下、离开页面或切到后台也会保存。下次用同一浏览器打开同一网址，点「继续上次的冒险」即可回到原处。休息时离开会从床边、长椅前或营火旁起身。旧位置变为障碍时，会回到该地图的安全入口。

收藏、已完成的心愿、七色花、落星、正式获得的饰品与搭配、认识的居民、遗迹的碑文与电波、星盘环、缺口和铜镜的朝向和七个小游戏的最高分都会保留。单局小游戏棋盘不续局。旧版存档会继续保留已获得的内容；第一次使用位置存档前从小屋开始。「重新探索」会清空游玩进度，保留音量设置和已下载素材。存档留在当前浏览器，清除站点数据会同时清除它和资源缓存。

首次游玩先准备小屋，继续存档则直接准备上次所在的地图。两种入口都会等背包、装扮、信箱和相册预览等公共资源就绪。芙芙沿粉白条纹跑向终点，右侧显示「已就绪数/必要总数」，图片解码后才计入。过门或切图时，目标地图独占下载队列，已经在下载的共用文件会继续使用。加载失败会留在原地，可以重试缺少的资源。其他地图空闲时续载，所有站内游戏资源齐备后才下载影片。

## 已包含的玩法

- 小屋的窗边、床左侧有一把白色四弦贝斯。点琴身或靠近按 E / 空格 / 右键打开窗边乐谱，为芙芙跟弹原创周年曲《把晚安弹给你》。琴谱在小屋原有的 3:2 画面内展开，手机上的四根弦并排排列。可以先「听示范」，再点亮起的弦（手机可轻触），或用 **1 / 2 / 3 / 4** 拨 **E / A / D / G**。四句共 16 个音，不限时，弹错可重试。弹完会在本机记下这份演奏；之后可以自由拨弦、再弹一次，或按 Esc 收起琴谱。示范按同一张谱播放，只跟随提示弹完才会记录赠曲。琴谱会在静音时提示原因，仍可按亮起的琴弦跟练。右上角的小喇叭恢复游戏声音，琴谱里的按钮单独开关琴声；总音量为零时点「恢复总音量」会恢复到 45%。
- 使用鼠标时，网页和地图使用芙芙的粉发爱心指针；指向可互动的地图物件、琴弦、按钮或链接时，箭头变成爱心拨片。触屏仍直接点按。
- 室内：长按吹蜡烛，依次沿三条虚线拖动切成六份，点小盘子观看芙芙吃蛋糕的过场；也可用键盘辅助切割。拆礼物时，点或向外拖开两端缎带，也可按 1 解开左端、按 2 解开右端。掀开盒盖后，再点「收下这份心意」领取缎带鞋。可以中途收起，也可以重看拆礼物的过程；奖励只收一份。
- 小屋书桌上摊开的是一本 13 个跨页的相册，开篇四张日常插画，后面 21 张按拍摄时间排列。点页签、按左右键或在书页上横滑可以翻页。点照片后先看到预览，等原图载入就能按原始大小看细节。退出单张会回到原跨页，再按 Esc 或「收起」返回探索。
- 室外：给三只气球充气并放飞；点夜空释放烟花与周年祝福；小电视打卡、CDN 周年放映。
- 电脑：WASD / 方向键移动，E / 空格互动，Esc 收起当前地图互动。
- 点击地图导航里的地名可切换场景，也可以走到门、出口或传送阵互动。游戏按窗口宽高保持 3:2 画幅，宽屏有足够侧边空间时，导航和触控键会排在地图右侧。
- 鼠标可独立游玩。左键点击地面寻路，点击物件或旁边的奶油色提示签走近互动。右键与地图物件互动，长按可吹蜡烛或蓄力跳跃。在扫雷棋盘上，左键翻砖，右键在指针下的砖上插旗或拔旗。
- 地图里的互动线索是物件边缘偶尔闪过的微光。走近后显示一个动作提示，如「翻开回忆相册」「与红笺交谈」；远处鼠标悬停显示「点击走近」，手机可轻触物件或提示签。NPC 靠近时用小对话气泡提示；七色花、落星、萤火与遗迹机关沿用自身光效。关闭背包或收起对白后，附近提示会立即恢复。
- 键盘可独立游玩。Tab 切换按钮，Enter / 空格确认。E 在当前互动中执行选项，长按 E 吹蜡烛，拆礼物按 1 解左缎带、2 解右缎带，之后按 E / 空格掀盖和收礼；E / 空格也保留按顺序辅助解带的操作。小游戏使用方向键 / WASD、空格。扫雷时用方向键选砖，按菜单键插旗或拔旗，也可用 Tab 选中「标记所选格」再按 Enter。
- 手机：虚拟方向键 + 互动按钮；也可以轻触地面自动寻路、轻触物件或动作提示签前往互动。
- 所有小游戏直接在地图里绘制和操作，蛋糕与礼物会拉近原场景镜头。烟花从实际烟花筒升空、气球从摊位飞走、视频在花园大屏播放。来信和相册都在游戏画面内展开。首页的回忆卡片可以带玩家前往对应物件。
- 家具碰撞、自动寻路、室外镜头跟随、本机探索进度、原创浏览器合成 BGM 与音效、减少动态效果支持。小喇叭一键静音或恢复，音量使用加减按钮。
- 四种陷阱集中在第三张「勇气花园」：松落的花藤、翘起的苔石、溪边薄雾、卷叶小风。它们贴合草地与石路，走近会出现「小挫折」提示。小屋与周年花园没有陷阱；普通家具仍有碰撞。所有陷阱都固定让芙芙回到小屋的床上躺下，已获得的徽章与回忆保留，不再有户外复活点。
- 小屋的床可以主动躺下，勇气花园的长椅互动后会真正坐下。按 E、方向键、虚拟方向键或场景中的「起身」按钮离开休息姿势；起身回到床边或椅子前的安全位置。走到勇气花园终点可摘勇气之花，获得「带一朵勇气回家」徽章。
- 两座花园的小溪有浅滩、苔石和随水漂流的花瓣或落叶，可以走木桥横穿。勇气花园的溪水在南侧树篱前收进水边石堆。烟花有心形、星形和金色花火。
- 周年花园的苹果放在气球摊东侧的果篮里，勇气花园可以从树上摘苹果。两处每天各有三颗。每片可采花丛每天有三朵花，另可捡花环和星屑。按 **B** 或点地图左侧的粉色背包图标，在「头饰」里戴上或摘下花环。
- 小镇有错落的主街、分岔小巷、阶梯院落、心形小广场、池塘和溪边街道。花店、烘焙屋、工坊、邮局、相册书屋和晚安电台沿街分散。18 位居民可在地图内交谈，迎宾员可赠送周年胸针。
- 六间商铺可朝正门向北走进去，也可在门前按 **E** 或点门。纪念馆在东侧石阶上平台设有一块小木牌，到牌前按 **E** 或点牌进馆。各室内从南侧门垫出门，回到刚才进屋的街道落脚点。店内窗光随时间变化，居民按班次进出。每屋的手作工作台支持拖动、按住、旋转和键盘操作。首次收下一件小物会盖同名徽章，在 **B → 纪念物 → 小镇小物** 回看成品。纪念馆的七格展柜会摆出已收下的小物。[七间店铺室内原画](doc/artwork/town-interiors/daylight-concepts/README.md)
- 晚安小屋里有只可以摸摸的小狐狸。点它，或走近按 E、右键、轻触互动键，就能和它打个招呼。
- 周年花园里，气球客星星带来了奶油猫桃桃。先摸摸它，再决定是否一起旅行。霉霉准备好了庆典，第二次找她可以邀请垂耳兔棉棉。篮子旁的晴糖有些害羞，等她亲手递出一块蛋糕吧。对话可随时收起，也可以回来重看。
- 放映草坪北侧是戴着大帽子的苏颜。走近按 E、右键或直接点她，和她聊聊后可以收下信，再选择「⌈现在读信⌋」。和小叶子聊起玩偶服，选「好热的拥抱」或「好温暖的拥抱」，它会一边回答一边递信，这时就能点「⌈收下信封⌋」。每次找它聊天，开场时可以问「小叶子，你知道去花海的路怎么走吗？」。第一次问就能收到手绘地图，之后可在背包的「纪念物」里翻看。
- 桃桃跟随时会转身、交替迈爪，追上芙芙后停步。与花园来宾和小镇居民对话时，走远会自动收起对白，按住的方向键和点击地面的寻路都会继续。
- 栅栏与水面有碰撞；树木、果实、NPC 与人物按脚底位置排序。夜间有蓝色环境光与暖色路灯、窗灯，烟花使用多组彩色粒子。

## 小镇小游戏与纪念背包

**回声遗迹**的入口在周年小镇右上角的废弃山洞。从广场沿东北石街走到旧矿场，经过矿车，沿两盏矿灯间的旧轨道向北走进洞口。也可以点击洞口、靠近按 E 或右键进入。遗迹南阶通回洞前空地，地图导航也能直达。

西廊蛇纹苔庭、北廊星图室、东廊琥珀矿井各保存一道铭文。触碰石座时就会抄下线索，可立刻返回探索。读齐三道铭文后，在中央祭坛翻阅拓本并尝试敲响符号。敲错会保留已经奏对的音，完整旋律会唤醒南阶旁的一处周年彩蛋。进度保存在本机，静音时可全程通过文字和石灯解谜。

编辑地图或替换壁画时参考[遗迹素材说明](doc/artwork/ARTWORK-v22.md)。

**支线「替芙芙点亮星盘」**约需 5–8 分钟。南阶石台提示三枚遗物的方位，守护者赠送的手记可以带去其他地图。按 **B → 纪念物 → 遗迹手记** 阅读，点书签或用左右方向键翻页。去西廊、北廊和东廊拾起藤纹内环、星纹中环和黄铜外环，再到中央祭坛西侧装入星盘。读盘沿的提示，让三道缺口对齐，沿光纹转动两面铜镜，使月光落到星纹砖上。完成时「晚安回声胸针」会自动入袋，可自行佩戴。原来的祭坛与隐藏电波仍可单独探索。

手记共有五枚印章，分别记录初次拾环、集齐三环、修复星盘、引光成功和听到旧电波。离开、刷新或关闭网页后，同一浏览器会记住每一格机关朝向，听过电波的旧存档也能直接看到对应印章。

- **祭坛听电波。** 触碰西、北、东三廊的试炼石座即可抄录碑文，顺序不限。西廊说叶子先落，东廊的铃回应落叶，北廊的星在铃声之后亮起。在中央祭坛依次敲「叶 → 铃 → 星」，到南阶旁的听月泉收听，就能获得「晚安收听员」印章。

两条线都可以静音完成，也可以随时离开小游戏继续探索。背包里的《遗迹手记》也收录了这两条解法，玩家可以自行揭晓谜底。

**扫雷怎么看数字？** 数字表示周围最多八块砖（含斜角）中的裂隙数量，空白会自动展开相连的安全区域。首翻的砖和它的邻格都安全。插旗只是做记号，带旗的砖要先拔旗才能翻开。翻到裂隙则本局结束，翻开全部安全砖即过关，无需给所有裂隙插旗。手机直接点砖翻开，用「触屏插旗」切换为插旗或拔旗。每盘有三次安全提示，可自动翻开未标记的安全砖。

手机使用游戏画面下方的方向与动作按钮。失败可立即重试，Esc 或「回到小镇」「返回遗迹」返回地图。达标时领取奖励后，可选择「继续游玩」保留分数继续挑战。跳一跳持续生成平台，连连看和扫雷换新盘，矿工补充新一层星矿。任意游戏达到双倍目标，可额外获得花环兔斜挎包。飞行中的星星在拾取后消失。奖励直接进入背包，每种只收一件。

跳一跳正常松手才会起跳。触摸被系统取消、按钮失去焦点或切到别的窗口时，会放弃这次蓄力，回到游戏后可以重新按住。

**暂停与恢复：**小游戏中按 **P** 或点「暂停休息」可停下，按 P / E / 空格或点「继续挑战」恢复。切到其他窗口/标签页会自动暂停小游戏，回到页面后等待主动继续。在地图探索时，打开背包仍可用键盘、鼠标和触屏控制人物。小游戏中查看衣橱或说明会暂停本局，收起后继续；若本来已经手动暂停，则仍保持暂停。昼夜时钟继续按现实时间流逝。Ctrl / Command / Alt 组合键保留给浏览器，不会触发游戏动作。

点一件已获得的配饰，粉框标出选择，左侧芙芙会试穿。选背包时芙芙会侧身，用镜子下方的箭头可以再转一圈。点「佩戴」确认，绿勾随即移到新搭配上。再点「脱下」可取下，伙伴的按钮为「同行」和「休息」。面板保持打开，可以接着换装。按 **B**、**Esc** 或点 **×** 收起，尚未确认的试穿会取消。键盘可用 **Tab / Shift+Tab** 选格、**Enter** 试穿和确认。正常模式下，确认的搭配保存在本机。睡觉时饰品与伙伴暂时隐藏，起身后恢复。

点击「开始」后，浏览器在本地演奏原创周年摇篮曲《把晚安留给你》。全曲 24 小节、六八拍，柔和的琴声唱出主旋律，拨弦、持续和声、低音与轻铃依次加入。小屋版本约一分钟，小镇速度略快。右上角小喇叭一键静音背景音乐、互动音效和贝斯，解除静音时恢复各自的设置。音符按钮单独开关背景音乐，游玩说明里的「互动音效」可以单独开关脚步等声音。花园放映时，视频独立控制音量。吹蜡烛使用长按操作。

贝斯提示资源播放失败时，恢复网络后重新点琴弦或「听示范」会重新加载失败的音轨，无需清档。浏览器播放权限提示与资源错误分别显示；示范中途失败会停止示范，收起、失焦或打开暂停面板也会停止琴声，返回后可再次演奏。

### 试穿与正式上线

网页右下角的 **⚙ 调试** 是测试入口。面板可以一边游玩一边查看，切图和刷新后仍然展开，关闭按钮固定在面板顶部。「网络下载」分别显示游戏资源和影片的实时网速。面板还可以切换碰撞轮廓、预览四个时段、定位地图与七朵花、临时打开花海、进入小游戏或体验贝斯、蛋糕、烟花、放映与陷阱复活。选「自然时间」回到正在流逝的游戏时钟。背包默认使用自己的收藏，手动开启「全饰品试穿」后可试穿 37 件物品。调试搭配仅在本次游玩生效，关闭试穿即可恢复自己的穿搭。在「调试 → 本机存档」里点「清空本机游戏存档」，再点「确认清空」会回到开始页。声音设置、已缓存的影片和贴图会保留。

正式发布时，把项目根目录 `.env` 中的 `VITE_WARDROBE_DEBUG` 改为 `false` 并重新构建，也可在 Cloudflare 的生产**构建变量**中设为 `false` 后重新部署。整个调试入口、花谱调试菜单和全饰品试穿都会隐藏；正常收花、解锁花海和背包不受影响。预览构建可继续使用 `true`。

## 七色花谱与花海

周年庭院有两朵特殊花，勇气花园有两朵，周年小镇有三朵。橙色花是金盏菊，已有的橙色收集记录会自动迁移。勇气花园的勇气之花是一簇白雏菊。开始探索后，每隔 30 秒，当前地图上还没摘的七色花会泛起约 3 秒的暖光。开启「减少动态效果」时光晕保持静止。可直接点击花朵，也可走近按 E 或右键采集。测试时在「调试 → 七色花与花海 → 七色花谱」查看线索和真实进度。

收齐七种花后，周年花园小叶子身旁的草地上会亮起七色传送阵，地图导航也会显示「花海」。走进阵心、点一下阵纹，或走近后按互动键，都能前往花海。这里一直是月夜。穿过草地上的野花，可以看到吃草的羊和萤火虫，也可以坐到营火边休息。要回庭院，去花海西边找泛着薄荷色微光的月芽传送阵，用同样的方式就能回到七色传送阵旁。

芙芙坐在营火边，空闲时每 7 秒有 47% 的机会遇到一段奇遇。小鸟、火蝴蝶、水母、烤棉花糖、星角幼鹿、月牙纸舟和云鲸每轮各出现一次。可以静静看，也可以在提示出现后的 6 秒内点击来客或道具、点休息栏按钮或按 F 回应。分别回应过七种自然出现的奇遇后，会获得「火光里的七次相遇」徽章。已回应的种类保存在徽章册里，可以分次集齐。奇遇中随时可以按 E、移动或点「起身」离开。派大星会在首次坐满 30 秒时来送信。

在「调试 → 花海营火奇遇」选择一种奇遇，会直接前往营火、坐下并开始演出。可以重复播放同一种，也可以中途换另一种。尚未收齐七色花时，这个入口会临时点亮传送阵。

花海有十四颗可拾取的落星，包括一橙橘小佑的金光五角星、故里的粉色小鱼、正号的十字星，以及电子羊的绵羊和小艾门的小猫。直接点落星，或走近按 E、空格、右键，即可看到一小束荧光烟花和一位制作人的署名、寄语。每颗只能拾一次。寄语在地图内阅读，长文可以滚动，点「收起」或按 Esc 返回探索。只有署名的星星会亮起一弯柔和的小星光，约六秒后淡去。七色花和落星分别保存在本机，跨天和刷新都会保留。「重新探索」会清空两项收集记录。

营火旁的星光瓶会在原有 3:2 游戏画面内打开锥形玻璃瓶特写。所有已拾星星都在同一个瓶子里自然散落，不分页；新增收藏不会挪动其他星星的位置。点击或轻触星星即可重读，也可用 Tab 切换、Enter 选读，按 Esc 或「收起」返回原地。桌面瓶子与寄语并排；手机还提供「上一颗」「下一颗」大按钮，只改变选中星、不隐藏其他星星，选中有留言的星星后可点「阅读寄语」。点「返回瓶中」继续挑选。没有寄语时显示姓名，并在选中的星星旁重放一小圈星光，不打开空白信纸。开启系统「减少动态效果」后，新星光改为静态亮点。

## 昼夜和限时彩蛋

现实 **1 秒等于游戏 1 分钟，24 分钟走完一个昼夜**。初次打开从 08:00 开始。小屋、两座花园和小镇共享昼夜变化。花海保持月夜，遗迹由长明灯照明，在两处停留时外界时钟继续走。清晨为 05:00–08:00，白昼为 08:00–17:00，黄昏为 17:00–20:00，星夜为 20:00–次日 05:00。刷新和切地图都会保留时间进度。旧存档首次打开时，会从原来的游戏天数和时刻接着走。

清晨的小屋窗下有杏色光带，黄昏窗光斜向床脚，夜间能看见窗外的蓝色和床边的暖灯。周年花园的桥面与溪水、勇气花园的木桥与林荫也随时间变色。

周年花园的小叶子和东北花径上的鸽子全天都在，放映草坪附近全天能找到苏颜。小佑、故里和浅笑全天在小镇。夜神华黄昏在溪边，晚上八点到午夜在电台内，其余时间在电台外的街上。正在聊天的人会等你把话说完。

夜色保留较明亮的地图底色、暖色灯光和月夜变化。烟花绽放时会在夜空中浮现周年祝福，逐渐升起、淡出；预设文字在 `src/celebration.ts` 的 `fireworkWishes` 中维护，不需要访客输入或后端。

页面不提供文字输入、留言提交、文件上传或录制功能。信件与媒体是维护者写入项目的只读内容。「留一格，给回忆」里的来信和相册卡都带玩家回小屋。走到对应物件后，游戏内会展开信摞或双页相册。点「收起」返回地图。

点游戏右侧或下方的「徽章」页签，即可查看收集进度和最近获得的徽章。点「地图」切回地图导航。新徽章会在网页右上角逐枚提示，提示音跟随互动音效和总音量。徽章册按日常与相遇、周年来信、游园小游戏、探索与彩蛋、进阶与陪伴分为五章，共 64 枚。点徽章查看条件和个人纪录。隐藏章先留一条线索，发现后再揭晓。

新存档从 0 枚开始。Kerry、Rabe 和小艾门的信要实际拆开才盖章，其余来信在收下或投递时盖章。小游戏采用单局最高分，达标后可以继续当前一局冲刺进阶章。开始或继续冒险以后，前台在线陪伴满 24、72、168 分钟各有一枚徽章，对应 1、3、7 个游戏日。读信和营火陪坐也计时。时间跨会话保存，多个标签页共用一只计时器。

文字与像素素材分开处理：界面使用微软雅黑 / 苹方等系统字体，游戏画布按实际显示尺寸与设备像素密度渲染；位图素材仍保留像素边缘，文字不再随低分辨率画布一起放大。问号按钮内提供完整操作说明。

### 新增一张照片

1. 将 PNG、JPG、JPEG 或 WebP 原图放在 `artifacts/r2/相册/`，并将同名文件上传到 R2 的 `1-year/picture/`。四张开篇插画也保存在这个本地目录。首次克隆后可直接使用已提交的清单和预览；需要重新制作某张预览时，从清单的 `originalUrl` 取回对应原图即可。
2. 运行扫描。新照片追加到 [album.json](ref/相册/album.json)，得到稳定的 `id`、`title`、`originalUrl`、尺寸和内容版本。普通文件名用作默认标题，CharaStudio 的时间戳文件名会转为拍摄日期和时间。
3. 想给照片起名时，直接改该条的 `title`。可选的 `text` 是配文，`alt` 是图片描述。整个相册使用 `photos` 数组的顺序。新照片的默认原图地址由 `originalBaseUrl` 与文件名组成，使用其他对象路径时填写这张的 `originalUrl`。

游戏相册使用 [previews/](ref/相册/previews) 中的两档 WebP。书页图长边最多 640px，缩略图最多 240px，均由本地扫描生成。预览与背包、徽章和信笺同属公共资源，无论从哪张地图进入都先备齐；点开单张后才从 CDN 取原图。提交更新后的 `album.json` 与预览即可发布新照片。四张开篇插画的原画与制作记录见 [v36 美术说明](doc/artwork/ARTWORK-v36.md)。

### 新增一封来信

现有信件集中在 [letters.json](ref/来信/letters.json)。可以在数组中追加一条，也可以在同目录放一个像 `letter-013.json` 这样的文件，内含一封信或一组信。文件名用于整理文件，信封上的署名与标题取自 JSON，可以写中文、表情、斜线或问号。

```json
{
  "id": "goodnight-010",
  "title": "今晚睡得好吗？",
  "author": "小月亮 / 月光邮局",
  "text": "芙芙，晚上好！\n\n今天也想送你一声晚安。"
}
```

新公开信省略 `delivery`，即可在游戏内的晚安信箱看到带蜡封的信。保留已发来信的 `id`，玩家的已读记录会继续对应原信。剧情来信的领取方式见[维护手册](MAINTENANCE.md#剧情来信与已读记录)。

新增文件后运行 `npm run scan:letters`，提交来信 JSON 和更新的索引。游戏会将已收到的信纳入桌上同一摞，页码随收信数量更新。

每封信还可以有自己的信封图案、火漆印纹和信纸。来信扫描只读 `ref/来信/` 顶层的正文 JSON。所有外观都在其子目录 [信笺](ref/来信/信笺/README.md)，由 [config.json](ref/来信/信笺/config.json) 按来信 ID 配置。未设置的来信使用通用铃兰信笺。

### 新增一颗落星

在 `ref/花海星星/` 下为每颗星放一个 JSON 文件，也可用独立子目录的 `star.json`。例如 `moon.json` 可以写成下面这样。

```json
{ "id": "star-moon", "name": "小月亮", "message": "愿每个晚归的人都能看到自己的星星。", "shape": "plain" }
```

填入唯一且稳定的 `id` 和展示署名 `name`。寄语 `message` 可留空，`shape` 可选 `plain`（普通）、`cross`（十字）、`gold`（金色）或 `pink-fish`（粉色小鱼）。新星省略 `position` 时由扫描器安排在可达的草地。指定落点可填 `"position": {"x": 301, "y": 414}`（此坐标已由小佑使用），需要调整展示顺序时填写 `order`。草地与星光瓶会读取同一份署名、外形和寄语。

要使用自己的画，把透明 PNG 或 WebP 和 `star.json` 放进同一个角色文件夹。例如在 `ref/花海星星/月亮船/` 里放一张 `月亮船.webp`，旁边的 `star.json` 写成：

```json
{ "id": "star-moon-boat", "name": "小月亮", "message": "我们一起去看星星。", "sprite": "月亮船.webp" }
```

运行 `npm run scan:stars` 后，草地上的落星和瓶中的收藏都会按原比例显示这张图。图片建议紧贴轮廓裁去多余留白，文件名避开 `#`、`%` 和 `?`。图片会随全量游戏发布。

### 花园大屏：CDN 周年放映

周年花园的大屏起初展示庆祝芙芙一周年的海报。小叶子知道怎样进入花海、到哪里找录像带。在花海篝火左边收下周年录像带时，会获得「藏在花海的这一年」徽章。带录像回周年花园，到放映机前选择放入录像带，即可在地图的大屏上观看。录像带从拾取时起就收录在**背包 → 纪念物**里，插带后仍可查看，状态显示为「已放入放映机」。点手账里的「花园大屏 · 周年放映」可以自动走到放映机前。插入状态随进度保存，下次回来可直接观看。

`src/cinema-config.ts` 的 `gardenFilm.src` 配置 CDN 视频地址，`title` 配置片名。花园播放 R2 上的周年正片 `1-year/video/fmm-1-year-video-compressed.mp4`。本地副本放在 `artifacts/r2/周年视频/`，沿用对象文件名。更换放映内容时更新 `gardenFilm.src` 并重新构建。

- **全部站内游戏资源备齐后才异步准备影片**，不阻塞游玩。首次下载显示已接收的字节数与百分比，推荐 H.264 + AAC MP4。已有缓存时同样等游戏资源就绪，再向 CDN 发 HEAD：优先比对 `ETag`，读不到时同时比对 `Last-Modified` 和 `Content-Length`。版本一致就播放本机完整副本。
- 电影等待游戏资源时会显示排队提示。开始下载后，地图内的放映屏、控制条和全屏播放器都显示下载量。服务器提供文件大小时还会显示百分比和进度条。下载或缓冲期间都可以点「离开，先去逛逛」或按 Esc，稍后回来观看。失败时可点「重新加载」。
- 连续 **60 秒没有收到任何数据** 会取消卡住的请求并显示重试；每收到一段有效数据都会延长等待，不限制整段视频的总下载时长。重试会从头下载完整文件。HTTP 206 分段响应、空文件和长度不完整的文件不会误判为预载完成。
- 当前正片约 204.3 MiB。文件完整接收并校验后才写入浏览器的 Cache Storage。通常从本机副本播放，浏览器无法播放本机副本时会改用 CDN 视频直链。同地址换片或无法确认版本时重新下载，新片完整前保留旧副本。暂时连不上 CDN 时，已有完整副本可以继续播放。浏览器拒绝持久缓存时，仍可播放本次下载的影片。
- 离开电视或切到后台会暂停播放，正在进行的下载仍可继续。回到当前页面可从暂停处接着看，刷新后播放时间从头开始。视频不写入游戏存档，也不进入静态部署包。
- 加载失败时可以点「重新加载」，也可以在放映画面按 E、空格或右键重试；需要等待时仍可离开探索。
- 鼠标按钮、E / 空格 / 右键均可播放暂停，左右方向键可跳转 10 秒，**F 或「全屏观看」进入全屏**，Esc 返回地图内观看。全屏提供浏览器原生控制条、「返回地图内观看」和「离开放映」；不支持原生全屏时使用全窗口播放器。控制条也提供快进、后退、重播和视频静音。地图内从按下播放起，游戏音乐和音效都静音，暂停或播完后按原设置恢复。全屏期间始终保持游戏静音，包括视频暂停时。

全屏看视频时，背包快捷键暂不生效。先返回地图内观看，再按 B 整理背包；这样不会打开藏在播放器背后的衣橱。进入全屏时键盘焦点也会进入视频播放器。

完整预载需要 CDN 允许 CORS 读取。公开纪念站可在 R2 桶的 Settings → CORS Policy 填入以下配置；使用自定义域名时，修改后清除视频 URL 的旧 CDN 缓存。配置依据：[Cloudflare R2 CORS](https://developers.cloudflare.com/r2/buckets/cors/)。

```json
[
  {
    "AllowedOrigins": ["*"],
    "AllowedMethods": ["GET", "HEAD"],
    "AllowedHeaders": ["Range"],
    "ExposeHeaders": ["ETag", "Last-Modified", "Content-Length", "Content-Range", "Accept-Ranges", "Content-Encoding"],
    "MaxAgeSeconds": 86400
  }
]
```

开发时可用带 `Origin` 请求头的 HEAD 请求检查响应是否包含 `Access-Control-Allow-Origin`。正片支持用修改时间和长度校验。显式暴露 `ETag` 可区分同一秒内替换的同大小文件。只允许 `http://localhost:3000` 无法覆盖本项目的 5173 / 4173 本地预览和 Cloudflare 正式域名。此配置仅允许读取，不开放上传接口。

## 陷阱、复活点与鼓励文案

`src/maps.ts`、`src/town-map.ts`、`src/ruins-map.ts` 和 `src/meadow-map.ts` 定义六张地图的可行走边界、家具、树干、水面、互动位置与陷阱。`src/landscape.ts` 的溪水形状同时用于绘制与碰撞。碰撞以脚下的小圆形区域计算。角色图集不是严格对齐的网格，`src/sprite-frames.ts` 使用各姿势的实际裁切范围、统一缩放与脚底基线；坐姿和睡姿也使用真实轮廓裁切。点击物件或提示签时，自动寻路会绕开家具、水面和陷阱；点击陷阱本身可以体验一次复活。

唯一复活点和起身位置在 `src/rest.ts` 的 `HOME_BED` 中。每次触发陷阱回床时，都会自动展开地图里的床边便签，文字为「小叶子让你休息一下再重新出发，辛苦啦宝宝」，完整配上用户提供的四格插画。原图保存在 `src/assets/xiaoye-note.png`，网页使用优化后的 WebP；样式与内容在 `src/bed-note.ts`、`src/world-details.css`。便签不阻塞游戏，没有弹窗遮罩。

第一次复活后，床边会保留便签图钉，平时也可重读。下一次触发任意陷阱时，便签会重新自动展开。

维护者可以在 `src/content.ts` 的 `encouragements` 添加鼓励语。第二次及以后的复活会把轮换文字附在原便签下方。

```ts
{ title: '可选标题', message: '在这里填写鼓励的话。', author: '可选署名' }
```

开发时访问 `/?debug=collision` 可以显示家具轮廓、可行走边界、脚下碰撞区域、路径和坐标，便于核对地图。这一 URL 开关只在开发服务生效；启用了调试台的静态构建也可在右下角开关碰撞轮廓。

### 周年开门时间与两种构建

晚安小屋在 **北京时间 2026 年 12 月 1 日 22:10** 开放。全部时区使用同一时刻。以前打开的倒计时标签页也能等到开门，玩家可以继续使用原有存档。

| 发布阶段 | 生产构建变量 | 同一网址的行为 |
| --- | --- | --- |
| 11 月 30 日之前 | `FULL_BUILD=false`、`VITE_WARDROBE_DEBUG=false` | 只发布独立的淡粉色周年邀请函，包中没有游戏和视频地址。 |
| 11 月 30 日提前发布 | 改为 `FULL_BUILD=true`，保留 `VITE_WARDROBE_DEBUG=false`，重新构建并部署 | 倒计时页先加载并显示邀请函，再在后台预载游戏资源。到点后打开游戏，复用已缓存的素材，并优先补齐起始地图。 |
| 12 月 1 日 22:10 | 使用前一天已部署的全量版本 | 浏览器按设备时钟自动进入游戏首页。 |

在 Cloudflare **Settings → Build** 中填写**构建变量**。修改后需要重新构建。省略 `FULL_BUILD` 或留空会构建全量版，其他非空值仅接受小写 `true` 和 `false`。查看站点的 `/release.json` 可核对上线的是 `lite` 还是 `full`。

如果玩家打开的是旧精简页，归零后会看到「小屋正在准备开放」。页面每 30 秒检查一次，恢复联网或切回标签页也会检查。等到同源的 `release.json` 与首页都指向同一个全量版本，页面就会自动刷新。CDN 短暂返回旧首页时会继续等待并重试。首页与版本标记允许重新验证，带哈希的插画和脚本可长期缓存。以前已经公开过的资源和玩家已下载的副本不会随部署撤回。

本机调试可在 `VITE_WARDROBE_DEBUG=true` 的页面右下角打开「调试 → 开放时间」，输入北京时间、选择「10 秒后开放」或「恢复正式时间」。调试只影响当前标签页，刷新保留；生产关闭调试后使用正式时间。全量调试版到点可进入小屋，在游戏调试面板把时间设到未来即可回到邀请函。精简调试版只能预览等待页面。

在 PowerShell 中可用 `$env:FULL_BUILD='false'` 后执行 `npm run build`、`npm run preview` 验证精简产物。将变量改为 `true` 即可测试完整切换。运行 `node --experimental-strip-types --test tests/launch-build.integration.ts` 可验证在同一输出目录连续构建时的资源隔离。

发布前可再运行 `node --experimental-strip-types scripts/verify-release.mjs`。它在临时目录构建两种关闭调试的产物，用浏览器验证邀请函加载失败后重试、到点切换、旧标签页升级，以及正式游戏中的装扮锁定、跨标签读信、相册、资源缓存、断网切图和续档。它不修改正式开放时间或本地开发配置。全徽章实玩路线另用 `node scripts/verify-badge-route.mjs 390`（宽度可改为桌面尺寸）。两个脚本需要可用的 Playwright Chromium；可用 `PLAYWRIGHT_MODULE` 指向本机的 `playwright-core`，Windows 默认使用已安装的 Edge。

运行 `node scripts/verify-game-time.mjs` 可在本机浏览器复测双标签采集、午夜补货、长椅跳时与 NPC 班次、前台陪伴计时，以及重新开档后的七色花提示。

5. 后续推送到远端 `main`，或把 Pull Request 合并进 `main`，都会自动运行构建与部署。可以在 Cloudflare 的 Builds 中查看对应提交的日志和发布结果。

```sh
git push origin main
```

触发条件是远端 `main` 收到新的推送；只在本地 `git commit` 尚未推送时，Cloudflare 不会收到事件。预览构建用于其他分支，不是生产自动发布的开关。

如果没有自动发布，优先检查 GitHub 应用是否授权此仓库、Git 构建连接是否启用、生产分支是否确实为 `main`，以及 Cloudflare 的构建日志。若项目最初通过直接上传创建，需要先建立 Git 构建连接。

以上行为依据 [Cloudflare GitHub integration](https://developers.cloudflare.com/workers/ci-cd/builds/git-integration/github-integration/) 与 [Build branches](https://developers.cloudflare.com/workers/ci-cd/builds/build-branches/)。
