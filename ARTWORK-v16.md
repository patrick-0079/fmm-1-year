# 夜间花海与花园采集物

地图和两张透明图集使用内置 imagegen 生成。原图保存在 `src/assets/`，运行 `npm run art:night` 可重建游戏使用的 WebP。

地图原画为 1536 × 1024，对应 900 × 600 的逻辑场景。帐篷与营火使用原画坐标，羊、萤火和可拾取的星在运行时独立绘制。导出时从同一张草地裁取了几小簇月光下的野花，柔化草地交界再散放到草坪中部。

每张图集按两行两列裁切，去掉透明边缘，等比装入 192 像素方格并对齐脚底。两种羊姿态用相同朝向绘制，朝左时在游戏里翻转。苹果和花丛可逐个移除，纸船只在对应时段出现。
